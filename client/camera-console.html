Sanbot Camera Viewer

A browser-side camera console for the bridge. Preview the MJPEG stream, grab stills, and inspect the live bridge state without bouncing between terminal windows.

This tool is tuned for quick field checks: one place to confirm the camera path, validate the API key, and watch what the robot is exposing right now. JSON endpoints now return type: "response" and a numeric code in their envelopes.

How It Works
  • The preview uses /v1/stream/camera/video with the API key in the query string.
  • The WAV audio stream is exposed at /v1/stream/camera/audio with the API key in the query string.
  • A recorded WAV file can be fetched from /v1/media/camera/audio?duration=3000.
  • The image button fetches /v1/media/camera/image with the API key header.
  • The face button fetches /v1/media/camera/face with the API key header when you want the latest cached face image.
  • Camera configuration is available through /v1/command/camera/config in the REST and WebSocket consoles.
  • The status button reads /status and shows the raw code/data JSON response envelope below.
  • If the robot IP changes, update the Bridge URL field first.
