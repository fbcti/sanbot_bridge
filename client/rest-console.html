Sanbot Bridge REST Explorer

Swagger-powered REST documentation for the bridge, kept inside the same tool suite as the WebSocket and camera utilities. The layout stays Swagger-native, but the framing and styling now match the rest of the toolkit.

This page is aligned with the current bridge routes, including `/v1/command/<module>/<action>` where applicable, plus the helper `/status`, `/openapi`, and camera endpoints. REST requests may include an optional correlation `id`; JSON responses echo it when present and report outcome with numeric bridge result codes.
